# カードゲーム（フレームワーク版）

友達とリアルタイム対戦できる、オリジナルカードゲームの**土台**です。
PC・スマホ両対応（レスポンシブ）。デザインや細かいルールはこれから組み込みやすいよう整理してあります。

## はじめに

VS Code での起動手順は **[VSCODEの使い方.md](./VSCODEの使い方.md)** を見てください（初心者向け）。
ざっくりは「Node.js を入れて → このフォルダを開いて → F5 or `node server.js` → http://localhost:3001」です。

## 主要 3 機能

1. **カード作成**（`#/cards/new`）… ①名前 ②コスト(1〜3) ③イラスト ④説明文 ⑤タグ
   - カード名はカード幅からはみ出さないよう**自動で文字サイズを縮小**
   - イラストは**アルバムから選択**し、**拡大縮小・上下左右移動**で見せたい部分を調整
     （枠は必ず画像で埋まり＝余白なし、画像が枠の内側にはみ出さないよう移動を制限）
2. **コレクション / デッキ編成**（`#/decks`）… カードの確認・編集とデッキ作り
   - カード一覧の端の「デッキ」ボタン → 既存デッキ一覧 +「新規編成」
   - デッキは **合計9枚 / コスト1・2・3を各3枚ずつ**。スロットを押して入れ替え、名前を付けて保存
3. **オンライン対戦**（`#/battle`）… **パスワード部屋**で1対1、相手がいなければ **CPU 対戦**
   - 2フェーズ制のターン戦。準備→毎ターン「お題」が出る→手札から1枚選ぶ→両者の札が公開→
     どちらがお題に合うか互いに評価（勝ち/負け/引き分けを両者が押して一致で成立）→
     勝者は自分の出した札のコスト分を得点→出した札は墓地へ。戦場が尽きるとフェーズ終了。
   - フェーズ2まで終えたら合計得点が多い方の勝ち。最後に「再戦」か「対戦を終了」を選択
   - お題の評価はプレイヤー同士の合意で決める方式（CPU戦ではあなたの判定にCPUが合わせます）

## スマホの画面向き

- カード作成 … **縦画面**推奨
- 対戦 … **横画面**推奨

向きが合わないときは「画面を回してください」の案内が出ます（PC では出ません）。
※Web では端末の向きを強制ロックできないため、案内表示にしています。

## 動かし方（コマンド）

依存パッケージは **ありません**（Node 18 以上の標準機能だけ）。

```bash
node server.js           # → http://localhost:3001（デフォルト）
PORT=8080 node server.js # ポートを変更したい場合
```

### 対戦を試す
1. ブラウザを2つ開く（別ウィンドウ/別端末）
2. 両方でカードを作り、デッキを1つ用意
3. 両方で「③ オンライン対戦」へ
4. 一方が「パスワードで対戦 → 部屋を作る」、もう一方が同じパスワードで「参加する」
5. 相手がいなければ「CPUと対戦する」で練習可能

        ├── store.js       カード/デッキの保存（localStorage）

## これから拡張する場所（目印）

- **デザイン** → `public/css/style.css` の `:root` 変数を中心に。
- **イラスト枠の形** → `imageCropper.js` の `ART_ASPECT` と CSS の `--art-aspect` を合わせて変更。
- **カードの項目を増やす（攻撃力など）** → `models.js` の `createCard()`（`attributes` も利用可）。
- **デッキ構築ルール（各コスト枚数・合計）** → `models.js` の `DECK_RULES` / `validateDeck()` / `isDeckComplete()`。
- **CPU の選択ロジック** → `cpu.js`（`pickCard()` を賢くすると強くなる）。
- **バトルのルール（進行・採点）** → `game.js`。お題の一覧は `THEMES`、フェーズ数は `TOTAL_PHASES`。
  画面表示は `screens/battle.js`。サーバー側で判定/チート対策をするなら `server/lobby.js` の `_handleAction()`。
- **新しい通信メッセージ** → `protocol.js` に種別を足し、`net.js`／`lobby.js` にハンドラ追加。
- **新しい画面** → `screens/` にファイルを作り `main.js` に `registerRoute()` を1行追加。

## 補足

- カード/デッキはブラウザの localStorage に保存（端末ごと）。画像は容量節約のため縮小して保存します。
  本格運用ではサーバー保存/画像ストレージへ（`store.js` / `cardImage.js` を差し替え）。
- 対戦の通信は今は「2人をつないで操作を中継」する薄い実装です。チート対策で
  サーバー側に判定を持たせたくなったら `lobby.js` に状態管理を足してください。
- WebSocket サーバーは学習・小規模向けの自作実装です。大規模/本番では `ws` 等への差し替え推奨。
